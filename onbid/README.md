# 온비드 주간 스카우팅 (onbid/)

온비드(www.onbid.co.kr) 공매에서 매주 세 갈래를 골라 권리분석·사진판단 리포트 초안을 만든다.
법원경매(courtauction.go.kr)와 등기부 실시간조회(iros.go.kr)는 쓰지 않는다.

| 트랙 | 대상 | 조건 |
|---|---|---|
| A 지분경매 | 부동산 · 매각 · 지분물건 · 압류재산 | 최저입찰가 300만원 이하, **수도권·강원·충청 소재만** |
| B 동산 재판매 | 동산 · 매각 | 100만원 이하, 노트북/PC/카메라/렌즈/귀금속/금/시계, 지역 무관 |
| C 자동차 | 자동차 · 매각 | 500만원 이하, 경유차는 조기폐차 지원금 분석, 지역 무관 |

사용자 조건: 성인 1인, 자차 없음, 온비드 전자입찰로 집에서 처리, 소송 없이 협상·재매각만.

## 실행

Node(Playwright + Chromium)와 Python 3(Pillow), poppler-utils(pdftotext·pdfimages·pdftoppm)가 필요하다.
클라우드 세션 이미지에는 모두 들어 있다.

```bash
python3 -m onbid.run --out out/onbid              # 검색→상세→사진·감정평가서→초안 (15~25분)
python3 -m onbid.run --out out/onbid --skip-search  # 검색 결과 재사용, 끝난 상세는 건너뜀
```

산출물
- `out/onbid/report_draft.md` — 숫자·원문이 다 채워진 초안. `⟪…⟫`만 사진을 보고 채우면 된다.
- `out/onbid/candidates.json` — 후보별 전체 데이터(등급 근거, 회차표, 등기 행, 명세서 원문, 지원금 추정).
- `out/onbid/media/<물건관리번호>/` — `photos_sheet.jpg`(온비드 사진 모음), `appraisal_sheet*.jpg`
  (감정평가서 중 사진·도면이 든 쪽 모음), `apsl-pNN.png`(쪽별 100dpi), `appraisal.txt`(글자 층이 있을 때).

## 단계

1. `js/search.js` — 조건검색 3종을 100건씩 페이지 넘겨 받는다(입찰기간 오늘~1개월, 사이트 기본값).
2. `analyze.select_*` — 1차 선별. A는 지분(`alcYn=='Y'`)·압류재산·권역, B는 키워드·가산점, C는 경유·연식 우선.
3. `js/details.js` — 후보별 상세 화면, 등기·점유·임대차·배분요구 조각, 사진 목록, 공매재산명세서.
4. `parse.py` → `analyze.build_*` — 리스크 등급, 회차표, 플래그, 지원금 추정, 정렬.
5. `media.py` — 상위 후보의 사진과 감정평가서 PDF를 받아 모음 이미지를 만든다. 링크도 이때 확인한다.
6. `report.py` — 초안 작성.

## 온비드 동작에서 확인한 사실 (코드가 기대는 부분)

- **조건검색 폼은 화면의 첫 자동검색이 끝나야 채워진다.** 빈 폼으로 검색하면 서버가 "지금 입찰중"인
  물건만 돌려줘 다음 주 입찰 예정 물건이 빠진다(288건 → 35건). `search.js`가 기다렸다가, 그래도 비면 기본값을 직접 넣는다.
- **지분여부 필터(srchAlcYnType)는 서버에서 무시된다.** 응답의 `alcYn=='Y'`로 직접 거른다.
- **상세 화면은 POST 이동으로만 열린다.** 직접 GET은 400. 단, 공유용 형식
  `mvmnCltrDtl.do?cltrScrnGrpCd=&cltrPrptDivCd=&onbidCltrno=&onbidPbancNo=&pbctNo=&pbctCdtnNo=`
  (이 6개만)은 GET으로 열려서 리포트 링크로 쓴다.
- **등기사항증명서 주요정보·점유관계·임대차·배분요구는 XHR 조각으로 늦게 채워지고 3~10건씩 페이지가 나뉜다.**
  `pageUnit=100`으로 직접 다시 받아야 공유자가 빠지지 않는다.
- **공매재산명세서는 ClipReport 뷰어 팝업이다.** 입찰 시작 7일 전부터만 버튼이 생긴다. 리포트 서버 응답의
  `viewData`(base64 JSON, 글자 단위 URL 인코딩)를 풀어 텍스트로 만든다. 인수권리·지상권·기타 유의사항은 보통 2쪽이라
  "다음" 버튼을 눌러 받아야 한다.
- **감정평가서 PDF는 로그인 없이 받아진다**(`dnldFile.do?atchFileLstNo&atchSn&hashCrpsNo`, 값은 상세 화면의
  `fn_chkPdfRead(...)`). 토지 감정평가서에는 위치도·지적도·위성사진·현장사진이 있고, 자동차 감정평가서(오토마트 등)는
  스캔본으로 감정평가표(상태 체크)·사고이력 보고서·차량가액 범위가 들어 있다. 한 감정평가서가 여러 물건(기호1·기호2)을
  함께 다루기도 하니 주소·기호로 해당 물건을 골라 본다.
- **사진은 `inqCltrMapImg.do` 팝업 조각에 URL 목록이 있고 GET으로 받아진다.**
- 지자체(예: 전북특별자치도) 공고 동산은 명세서·감정평가서가 hwpx 첨부라 자동 열람하지 않는다. 사진으로 판단한다.
- 클라우드 세션의 프록시는 온비드 외 대부분 도메인을 막는다. 배출가스 등급 조회 같은 외부 사이트는 자동 조회하지 않는다.

## 판정 규칙

### Track A 리스크 (사용자 지침)
- 낮음: 농지 아님 + 공유자 없음(또는 전원 10년 이상 지나 비활성 추정) + 인수권리·점유자 없음
- 중간: 농지 아니지만 공유자 있음. 등기 주요정보가 0건이라 공유자를 확인할 수 없는 경우도 중간
- 높음: 농지이거나 실제 인수권리(명세서) 또는 점유·임대차 존재
- 정렬: 리스크 → 지목(임야·대지·도로·구거 > 기타 토지 > 농지) → 가격
- 다음 회차 가격은 추정하지 않고 온비드에 이미 등록된 회차표를 쓴다. 한국자산관리공사 압류재산은 매 회차
  최초 예정가의 10%씩 일정하게 내려간다(전회차의 88~90%라는 통념보다 빠르다).

### Track C 조기폐차 지원금 (`subsidy.py`, 2026년 기준)
- 대상: 배출가스 4등급 경유차, 5등급 차량. **5등급 지원은 2026년이 마지막.**
- 요건: 신청일 기준 **6개월 이상 소유** + 같은 지역 **6개월 이상 연속 등록**, 관능검사 적합, 대상차량확인 정상가동,
  정부지원 DPF·저공해조치 이력 없음, 자진폐차말소만 인정.
- 3.5톤 미만 4등급: 차량기준가액(보험개발원, 당해 1분기) × 70%(1차), 상한 800만원. 2차 30%는 전기·수소·하이브리드
  구매 시에만. 3.5톤 미만 5등급: 100%, 상한 300만원. 저소득층·소상공인 100만원 추가.
- 공매 낙찰차 적용: 낙찰·이전등록 후 6개월을 들고 있어야 신청 가능 → 5등급은 사실상 불가, 4등급은 2027년 사업
  지속 시에만 가능. 보유 기간의 보험·세금·검사 비용과 정상가동 탈락 위험을 빼고 계산한다.
- 연식으로 등급을 추정(≤2005 5등급, 2006~2009 4등급, 2010~2011 경계, 이후 3등급 이하)하되 실제 등급은 차량번호로
  자동차배출가스 등급제 누리집에서 확인해야 한다.
- 출처와 최신값은 해마다 `subsidy.RULES`와 이 절을 함께 갱신한다.
