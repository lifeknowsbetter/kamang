# 개발 사업 데이터 (`devzones.json`)

온비드 부동산 물건(Track A·D)이 어떤 개발 사업(반도체·대기업 투자, 공공택지·신도시, 산업단지, 교통, 신공항 등)과
위치가 가까운지 리포트에 사실로만 보여주기 위한 목록이다. 매칭·집계·검사는 `onbid/devzone.py`가 한다.

위치가 가깝다는 사실일 뿐 수익 근거가 아니다. 개발이익은 시세와 감정가에 이미 반영됐거나 공익사업 보상에서 배제될 수 있다.
그래서 순위의 보조 기준(같은 위험 등급·같은 거리 구간 안에서만)으로만 쓰고 위험 등급은 바꾸지 않는다.

## 파일 형식

```json
{ "schema": 1, "built": "YYYY-MM-DD", "note": "…", "entries": [ { … }, … ] }
```

`schema`는 형식 버전, `built`는 목록을 만든 날, `note`는 자유 메모, `entries`가 사업 목록이다. 파일이 없거나 읽지 못하면
리포트는 개발 연관 표시만 생략하고 나머지는 그대로 만든다.

## 항목 필드

| 필드 | 필수 | 설명 |
|---|---|---|
| `id` | ✔ | 영문 소문자·하이픈 식별자, 항목마다 유일 |
| `name` | ✔ | 사업명 |
| `kind` | ✔ | `devzone.KINDS` 중 하나: 반도체·첨단산업 / 대기업 투자·신설 부지 / 산업단지 / 신도시·공공주택지구 / 도시개발·재정비 / 교통 / 신공항·항만 / 기타 |
| `stage` | ✔ | `devzone.STAGES` 중 하나: 계획 / 구역지정 / 승인·착공 / 조성·건설중 / 준공·가동 / 보류·취소 |
| `sido` | ✔ | 시도 이름(온비드 표기, 예 `경기도`) |
| `sgg` | ✔ | 시·군·구 목록. 구가 있는 시는 `용인시 처인구`, 시 전체면 `평택시` |
| `summary` | ✔ | 출처에 있는 사실만 쓴 한 줄 요약 |
| `asof` | ✔ | 정보 기준일 `YYYY-MM` 또는 `YYYY-MM-DD`(확인한 날) |
| `sources` | ✔ | 출처 URL 목록(`http`로 시작, 1개 이상) |
| `confidence` | ✔ | `high` / `medium` / `low` |
| `emd` | | 읍·면·동 목록(읍면동 일치 매칭에 쓴다) |
| `neighbors_sgg` | | 효과가 직접 미치는 인접 시군구, 5개 이하 |
| `lat`, `lng` | | 중심 좌표. 출처에서 확인한 경우에만, 둘이 함께 |
| `investor`, `scale`, `schedule` | | 시행·투자 주체, 규모, 일정(출처에 있는 것만) |
| `land_rules` | | 토지거래허가구역·개발행위 제한 등 토지 거래에 영향을 주는 규제 |
| `boost` | | `false`면 표시는 하되 순위 보조에서 뺀다(설비 감축·구조조정처럼 위치가 가까워도 개발 신호로 보기 어려운 항목). 기본 `true` |

위치는 행정구역 이름으로만 적는다. 지번 단위 구역 경계는 적지 않는다. 행정구역 개편 이름은 `sgg`·`emd`에서만 새 이름과 옛 이름을 함께 적고, `sido`는 온비드 표기(예 `전남광주통합특별시`) 하나만 쓴다.
`sgg`·`neighbors_sgg`가 항목의 `sido`와 다른 시도에 걸치면 `서울특별시 중구`처럼 시도 접두어를 붙인다(접두어가 없어도 그 이름이 `geo.C`에서 한 시도에만 있으면
그 시도로 본다. `중구`·`동구`·`강서구`처럼 여러 시도에 있는 이름은 항목 `sido`로 본다). `neighbors_sgg`에 `수원시 영통구`처럼 구까지 적으면 그 구만 인접으로 본다.
세종특별자치시는 시군구가 없어 `sgg`에 `세종특별자치시`만 쓰고 읍면동은 `emd`에 쓴다. `emd`에 `을지로3가`처럼 N가까지 적으면 그 N가만, 번호 없이 `을지로`로 적으면 모든 N가와 맞춘다.

## 매칭과 표시

물건의 시도·시군구·읍면동 문자열(온비드 행의 `sidoSgkEmd`)을 항목과 가까운 순서로 맞춘다.

1. **읍면동 일치** — 같은 시(·구)이고 읍면동이 `emd`에 있다. 구역 안이라는 뜻이 아니라 구역이 걸친 읍면동이라는 뜻이다.
2. **같은 시·구(읍면동 미특정)** — 같은 시(·구)인데 항목에 `emd`가 없어 사업 위치가 읍면동까지 특정되지 않는다.
3. **같은 시·구 다른 읍면동 / 인접 시군구 / 노선 통과** — 항목에 `emd`가 있는데 물건은 다른 읍면동이거나, `neighbors_sgg`·같은 시 다른 구·
   좌표가 있으면 시군구 중심에서 12km 이내이거나, 읍면동 없이 여러 시군구에 걸친 노선·광역 사업(교통, `sgg` 3개 이상)이 지나는 시군구다.
   큰 시에서 '같은 시'는 가깝다는 뜻이 아니라서 사업 읍면동이 특정돼 있으면 3단계로 낮춘다.

한 물건에 여러 항목이 맞으면 단계 → 사업 단계(착공·조성 중이 앞) → 신뢰도 순으로 정렬해 최대 2개를 보여준다.
`보류·취소` 항목은 표시하되 순위 보조에는 쓰지 않는다. 리포트에는 물건 블록의 "🏗 개발 연관" 줄과, 상세를 열기 전 전체
압류 부동산 목록의 연관 집계표(`🏗 개발 사업 연관 물건`)가 들어간다.

**한계**: 온비드 행에는 좌표가 없다. 시군구 대표 좌표는 ±5km 정도 어긋나고(`geo.py`), 구역 경계를 지번 단위로 확인할 수 없다.
그래서 읍면동 일치도 "구역 밖일 수 있다"고 안내하고 고시 도면(토지이음)으로 지번을 확인하게 한다.

## 데이터 원칙

- 모든 항목에 출처 URL과 기준일이 있어야 한다. 출처에서 본 내용만 쓰고 지어내지 않는다. 모르는 값은 비워 둔다.
- 사업이 취소·보류되면 항목을 지우지 않고 `stage`를 `보류·취소`로 바꾸고 이유를 `summary`에 적는다.
- 기준일이 400일을 넘으면 검사가 경고한다. 낡은 항목은 다시 확인해 `asof`를 고친다.

## 미검증 후보 (`devzones_pending.json`)

같은 형식이지만 `status: "unverified"`와 `pending_reason`이 붙는 후보 목록이다. `devzone.py`는 이 파일을 읽지 않으므로 리포트에는 나오지 않는다.
2026-10-18에 있던 28개는 모두 검색으로 확인해 22개를 `devzones.json`으로 옮기고(건의·요구 단계이거나 개발이 아닌 구조조정 논의 6개는 뺐다) 지금은 비어 있다.
새 후보가 생기면 여기에 넣고, 공부 루틴(일요일 점검)이 항목마다 출처로 확인해 `devzones.json`으로 옮긴 뒤(`status`·`pending_reason` 삭제) 이 파일에서는 지운다.
확인하지 못한 것은 이 파일에 그대로 둔다(다음 점검에서 다시 본다). 사실이 아님이 확인된 것만 이 파일에서 지우고 journal에 이유를 적는다. 승격 때 같은 사업이 이미 있으면(사업명이 같으면 `validate`가 경고한다) 새로 넣지 말고 기존 항목을 갱신한다.

## 명령

```bash
python3 -m onbid.devzone validate                     # 파일을 못 읽거나 항목이 없으면 오류. 필수 필드·값 목록·id 형식·출처 URL·날짜·좌표·목록 형식, 맞춰지지 않을 시군구 이름·사업명 중복·neighbors 5개 초과는 경고(오류가 있으면 종료코드 1)
python3 -m onbid.devzone match "경기도 용인시 처인구 원삼면"  # 위치 문자열 하나의 연관 항목
python3 -m onbid.devzone scan out/onbid/search_A.json  # 검색 결과 전체의 연관 건수 집계
```

환경변수 `ONBID_DEVZONES`에 경로를 주면 다른 데이터 파일로 시험할 수 있다.

## 갱신 절차

- KST 기준 일요일의 공부 루틴(`onbid/LEARN_PROMPT.md` 2-1절)이 점검한다: 기준일이 오래된 항목 6~8개를 다시 확인하고 새 대형
  사업을 최대 3개 추가한다.
- 저장 전에 `python3 -m onbid.devzone validate`가 **오류 0**이어야 한다. 통과하지 못하면 되돌린다. 사람이 직접 고칠 때도 같다.

## 예시 항목 (가상의 값, 실제 사업 아님)

```json
{
  "id": "example-0001",
  "name": "예시 산업단지(가상)",
  "kind": "산업단지",
  "stage": "계획",
  "sido": "경기도",
  "sgg": ["예시시"],
  "emd": ["예시읍"],
  "neighbors_sgg": [],
  "summary": "형식 설명용 가상 항목",
  "asof": "2026-01",
  "sources": ["https://example.com/example"],
  "confidence": "low"
}
```
